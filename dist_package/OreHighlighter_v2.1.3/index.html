OreHighlighter

見えにくい鉱石を、見える化する。

ダイヤ鉱石などの対象ブロックが光って見えるリソースパックを、コマンドもプログラミングも使わずGUIだけで作れる、 ゲーミングブロック導入用アプリです。

素人が作ったので使いにくいところやご要望が有りましたら”優しく”教えて下さい。

⛏ ダウンロード v2.1.3 / Windows 使用マニュアルを見る

できること

初心者でも迷わないよう、面倒な設定はできるだけ自動化しています。

ブロックごとに個別エフェクト

ダイヤはレインボー、怪しい砂利は点滅など、対象ブロック1つ1つに別々の見た目を設定できます。

6種類のエフェクト

レインボー＋枠線／レインボー／レインボー（斜めグラデ）／枠線／枠線（レインボー）／点滅。v2.1.3からはアイテムテクスチャでも全種類使えます。太さ・彩度・明るさ・速さまで細かく調整できます。

体力・満腹度アイコン編集

HUDのハート・満腹度アイコンを9×9ドット絵で自由に描き替え。本物のアイコンと見比べながら編集できます。

jarの場所を自動で発見

公式ランチャーやPrism Launcherのルートフォルダを選ぶだけで、対応するバージョンのjarを自動で探し出します。

画面イメージ

対象ブロックの登録からリソースパック生成まで、すべて1つの画面で完結します。

TAB 01

読み込み

jarファイル・フォルダ・既存プロジェクト・既存パックのGUIアイコンなど、これまで各タブに散らばっていた 読み込み操作をここに集約。作業はまずこのタブから始めます。

TAB 02

ブロックエフェクト

テクスチャ一覧から対象ブロックを選んで登録し、ブロックごとにエフェクトとパラメータを設定。 アニメーションGIFでその場でプレビューでき、Prism Launcherのインスタンスも自動検出します。

TAB 03

GUIアイコン編集

体力・満腹度アイコンをドット絵エディタで編集。「保存する」を押すまでは下書き扱いになるので、 うっかり上書きしてしまう心配がありません。十字キーで1ドット単位の位置調整もできます。

実際に生成される「レインボー＋枠線」エフェクトの動作例。この見た目のまま、Minecraft内のブロックに反映されます。

更新履歴

バージョンごとの主な変更点です。

v2.1.3 最新
  • 「読み込み」タブを新設：jar・フォルダ・ランチャーの自動検出、既存プロジェクト、既存パックのGUIアイコンなど、各タブに散らばっていた読み込み操作を1つのタブに集約しました
  • エフェクトの名前を整理：「レインボー + 枠線」→「レインボー＋枠線」など、短く分かりやすい表記に統一。過去に保存した設定・配布済みのパックはそのまま読み込めます
  • アイテムテクスチャでも、ブロックと同じ6種類のエフェクトが使えるように：「レインボー＋枠線」「枠線」「枠線（レインボー）」を追加しました
  • アイテムの「レインボー（斜めグラデ）」で帯の本数・透過度の設定が効かなかった不具合を修正
  • ブロックエフェクトタブのテクスチャ一覧をウィンドウの高さいっぱいまで表示するように変更
  • アイテムテクスチャ編集タブのアニメーションプレビューを中央の列に移動し、設定を変えながら結果を確認しやすくしました
  • アイテムの外部PNG画像に関する注意事項を、プレビュー横の「⚠ 注意事項」ボタンにまとめ、マウスオーバー時のみ表示するように変更
  • GUIアイコン編集タブの「外部PNGをインポート...」を、保存する/コピー・ペーストのボタン群のすぐ下に移動
  • GUIアイコンのバックアップ書き出しが、保存に失敗しても前回のzipを壊さない安全な方式になりました
  • アイテムの外部PNG注意事項に、Minecraftのテクスチャが基本的に「2のべき乗の正方形」であることの参考情報を追加
  • GUIアイコン編集タブの色選択を軽量化：QColorDialogを丸ごと埋め込む方式から、プリセットのスウォッチ＋「他の色を選ぶ...」の方式に変更し、ウィンドウを小さく保ったまま使えるようにしました
  • 設定の自動保存先を変更：実行ファイルと同じフォルダから、Windows標準のユーザーデータ置き場（%APPDATA%）へ移動。新しいバージョンをダウンロードしてフォルダを入れ替えても、設定が消えなくなりました（旧バージョンの設定は初回起動時に自動で引き継がれます）
  • ウィンドウのタイトルバーに「OreHighlighter（バージョン）」を表示するように変更
  • 起動時に新しいバージョンが無いか自動で確認する機能を追加：GitHubの最新版より古い場合、画面上部に案内バナーが表示されます。バージョン確認以外の情報は送信されず、オフラインでもエラーは出ません
  • アイテムテクスチャ編集の「ドット絵エディタ」をGUIアイコン編集タブと同じ操作感に統一：色パレット・実寸に近い編集中プレビュー・オニオンスキン表示を追加しました
