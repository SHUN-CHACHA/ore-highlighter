# 鉱石視認性向上ツール GUI - 実行手順

## 1. 必要なもの

- Python 3.10以降（[python.org](https://www.python.org/)からインストール可能）
- 以下のライブラリ（一度だけインストールすればOK）

```
pip install PyQt6 Pillow
```

## 2. ファイル配置

`main.py` と `texture_effects.py` を、**同じフォルダ**に置いてください。
（`texture_effects.py`はエフェクト生成のロジック本体、`main.py`がGUI本体です）

## 3. 起動方法

そのフォルダをコマンドプロンプト（またはPowerShell）で開いて、以下を実行してください。

```
python main.py
```

ウィンドウが起動すれば成功です。

## 4. 使い方

画面は左から「テクスチャ一覧」「対象ブロック」「編集エリア」の3列構成です。

1. **「フォルダを開く...」**（展開済みのテクスチャフォルダを選ぶ場合）または **「jarから読み込む...」**（`26.2.jar`や`client.jar`を直接選ぶ場合。中の`assets/minecraft/textures/block`が自動で取り出されます）
2. 左側の一覧から、加工したいブロック（`diamond_ore.png`など）を選択し、**「→ 対象ブロックに追加」**
3. 中央の「対象ブロック」一覧から、設定したいブロックをクリックして選択
4. 右側の「このブロックのエフェクト設定」で、そのブロック専用のエフェクト（レインボー+枠線／レインボーのみ／枠線のみ／点滅）とパラメータを調整
   - **ブロックごとに別々の設定を持てます**（例: ダイヤはレインボー、怪しい砂は点滅、など）
   - 中央の一覧で複数選択した状態で設定を変えると、選択した全ブロックに一括反映されます
5. **「選択中のブロックをプレビュー」** で見た目を確認
6. **「出力設定」** で、パック名・説明文を指定し、出力先を決める
   - **「Prism Launcherのインスタンスを検出」** ボタンでインスタンス一覧から選ぶと、`resourcepacks`フォルダが自動設定されます
   - 検出されなかった場合は「参照...」から手動で選択
7. **「リソースパックを生成」** をクリック（中央の「対象ブロック」一覧にある**全ブロック**が、それぞれの設定でパックに含まれます）

出力先フォルダの中に、指定したパック名のフォルダがそのまま作られます（zip化はしていません。フォルダのままMinecraftから読み込めます）。既に同名のパックがあれば上書きされます。

## 5. 設定の保存・読み込み

**アプリを閉じるたびに（終了ボタン／×ボタンどちらでも）、現在の設定が自動的に`config.json`として`main.py`と同じフォルダに保存されます。** 次回起動時は、それを自動的に読み込んだ状態で立ち上がります。手動での「設定を保存」「設定を読み込み」ボタンは、別名で設定を書き出したい・別の設定ファイルを読み込みたい場合のみ使ってください。

## 6. 既知の制約（現バージョン）

- 「点滅」は2コマ固定です
